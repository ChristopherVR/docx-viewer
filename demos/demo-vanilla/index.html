Format support and fidelity

This editor supports paragraphs, direct text formatting, alignment, simple tables and basic page settings. It uses a continuous editing surface without Word pagination. Images, lists, headers, footers, fields, tracked changes and other advanced features are not rendered. Unsupported content is preserved when possible; edits that cannot be retained safely are rejected with a warning. Legacy DOC editing is limited to imported paragraph text. Export DOCX creates a new document from visible content.
